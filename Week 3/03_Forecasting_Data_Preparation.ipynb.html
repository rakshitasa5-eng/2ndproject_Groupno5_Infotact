for category in df["CategoryName"].unique():                                          ## Check Monthly Continuity

    category_data = df[
        df["CategoryName"] == category
    ].sort_values("OrderDate")

    expected_dates = pd.date_range(
        start=category_data["OrderDate"].min(),
        end=category_data["OrderDate"].max(),
        freq="MS"
    )

    actual_dates = pd.DatetimeIndex(
        category_data["OrderDate"]
    )

    missing_dates = (
        expected_dates.difference(
            actual_dates
        )
    )

    print(
        "\nCategory:",
        category
    )

    print(
        "Missing months:",
        len(missing_dates)
    )

    if len(missing_dates) > 0:
        print(missing_dates)

Validation Outcome¶

The monthly demand dataset was reviewed for forecasting readiness.

The validation included:

  • Required column verification
  • Datetime validation
  • Product category verification
  • Missing-value analysis
  • Duplicate record checks
  • Quantity validation
  • Chronological sorting
  • Monthly continuity checks
  • Category-wise observation counts
  • Demand statistics review

The validated data was exported as forecasting_ready_data.csv for the next stage of the Week 3 forecasting pipeline.

The next step is to perform a chronological train/test split and establish a baseline demand forecasting model.
